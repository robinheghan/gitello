# gitello
A text-driven trello clone with git storage

## Workflow

- **Feature requests**: open a [GitHub issue](https://github.com/robinheghan/gitello/issues/new/choose) with the *Feature request* template.
- **Implementation**: a Mistral agent implements each feature request in a PR linked to the issue (`Closes #<number>`).
- **Review**: every PR runs automated checks and gets an agent review before merge.

See [CONTRIBUTING.md](CONTRIBUTING.md) and [AGENTS.md](AGENTS.md) for details.
